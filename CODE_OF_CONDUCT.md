# Code of conduct / Código de conduta

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good intent and keep discussions about the work. Report problems privately to the maintainer through [GitHub](https://github.com/soulrocha).

Este projeto segue o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Seja gentil, presuma boa-fé e mantenha a conversa no trabalho. Relate problemas em privado ao mantenedor pelo [GitHub](https://github.com/soulrocha).
